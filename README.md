---

## 🌟 简介  
**TraceDialog** 是基于 **[VNDialog](https://github.com/YourZi/VNDialog)** 增量开发的对话引擎，为寻迹整合包自用引擎，故永不提供构建文件，如需使用请自行构建。

**TraceDialog** 90% 的代码来自 **VNDialog**，遵循 MIT 协议开源，本分支修改较多，已不适合向源仓库 PR。

**TraceDialog** 完全兼容 **VNDialog** 的数据包，所以教程请前往源仓库查看文档，新增功能不做介绍，请自行查看源码理解。

如遇问题请在本仓库提 [issue](https://github.com/Moirstral/VNDialog/issues/new)，切勿在源仓库提交。
